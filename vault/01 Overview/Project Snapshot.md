# Project Snapshot

## Product
Kairos is a local-first desktop productivity app built with PySide6. It helps the user:
- manage goals and tasks
- create a focused daily plan
- run Pomodoro sessions and breaks
- review progress, history, and consistency

## Current application structure
- **Today**: recommendation and daily planning
- **Dashboard**: metrics, heatmap, active goals, recent sessions
- **Goals**: goal and task management
- **Focus**: Pomodoro timer and session flow
- **History**: session archive

## Current strengths
- Clear core loop: plan -> focus -> log -> review
- Local JSON-based persistence
- Strong recommendation potential in the Today experience
- Existing dashboard and streak concepts provide a good foundation

## Current weaknesses
- Utility feel instead of premium feel
- Too much visual sameness
- Too many equal-weight actions
- List-heavy layouts
- Focus mode does not yet feel immersive
- Goals page feels closer to CRUD than strategy

## Success definition
Kairos should feel calm, premium, and intentional. The user should be able to open the app and know what to do within seconds.
