# UX Redesign Brief

## Problem
Kairos has a strong core loop: define goals, choose today's work, run focus sessions, and review progress. The product is functional, but it still feels like a useful utility rather than a premium desktop experience.

The main issues are:
- visual sameness
- heavy control density
- list-first layouts
- limited guidance at key decision points

## Product direction
Kairos should feel:
- calm
- clear
- intentional
- momentum-driven
- local-first and personal

The app should always answer:
1. What should I do now?
2. Why does it matter?
3. Am I moving forward?

## Experience principles
1. **Clarity over control**  
   Show the next best action first.

2. **Calm over density**  
   Use more whitespace, fewer borders, and stronger hierarchy.

3. **Momentum over management**  
   Keep the user moving with clear continuation states.

4. **Guided, not prescriptive**  
   Suggest confidently, allow override easily.

5. **Depth where it matters**  
   Prioritize Today and Focus first.

## Strategic direction by page
### Today
- Make it the command center
- Emphasize one recommended next block
- Keep today's plan intentionally small

### Focus
- Make it immersive
- Hide nonessential controls during active sessions
- Make transitions between focus and breaks feel smooth

### Dashboard
- Interpret momentum instead of only showing metrics
- Surface goal health and the next recommendation

### Goals
- Shift from CRUD-heavy layout to planning workspace
- Show meaning, progress, and next task before controls

### History
- Move toward a calmer session journal or timeline

## Premium feel definition
Premium for Kairos means:
- less friction
- calmer layouts
- stronger hierarchy
- cleaner copy
- smoother transitions
- more confidence in what the UI chooses to show
