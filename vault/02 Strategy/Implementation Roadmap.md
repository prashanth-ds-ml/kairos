# Implementation Roadmap

## Goal
Turn the redesign brief into a phased execution plan that improves product feel without losing the current working core.

## Phases
### Phase 1 - Foundation
**Status:** Next

Deliverables:
- visual language refresh
- typography hierarchy
- button and card hierarchy
- spacing and layout rules
- status presentation rules
- copy tone update guidelines

### Phase 2 - Today redesign
**Status:** Planned

Deliverables:
- hero recommendation area
- premium today queue cards
- quieter available-work section
- clearer summary strip
- better add/remove/plan-full feedback

### Phase 3 - Focus redesign
**Status:** Planned

Deliverables:
- immersive focus layout
- reduced running-session chrome
- distinct focus vs break states
- improved completion and transition states

### Phase 4 - Dashboard redesign
**Status:** Planned

Deliverables:
- insight-first summary
- refined metric cards
- better heatmap framing
- goal health section
- improved recent session presentation

### Phase 5 - Goals redesign
**Status:** Planned

Deliverables:
- richer goal browsing
- selected goal overview
- cleaner editing flow
- lighter inline task actions

### Phase 6 - History redesign
**Status:** Planned

Deliverables:
- session journal or timeline view
- improved readability and scanability

### Phase 7 - Polish
**Status:** Planned

Deliverables:
- micro-interactions
- empty state improvements
- notification polish
- consistency pass across the app

## Component inventory to define
- hero panel
- recommendation card
- stat card
- goal card
- task row
- status pill
- session feed item
- primary button
- secondary button
- ghost button
- empty state block

## Risks to avoid
- making the UI flashy instead of calm
- adding more controls during redesign
- losing clarity in the current working flow
- redesigning too many pages at once without a visual system

## Immediate next actions
1. Create the implementation workboard
2. Break Phase 1 into concrete tasks
3. Define page-specific UI changes before code work begins
