# Research Index

Kairos uses this folder for search memory and research that may become goals, notes, or questions.

Default memory policy:

- Store search queries only when the user saves them.
- Store clicked or saved results, not every result.
- Link research to a goal, area, North Star theme, or open question when possible.
- Use the read/save flow to turn search into durable memory instead of background browsing history.

The app syncs saved search memory into [[Search Memory]].
