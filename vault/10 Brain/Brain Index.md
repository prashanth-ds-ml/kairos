# Brain Index

Kairos uses this folder as the readable Obsidian layer for the local brain.

The app can sync:

- [[Profile]]
- [[North Star]]
- [[Current State]]
- [[Questionnaire History]]
- [[Search Memory]]

Principles:

- Raw answers stay separate from summaries.
- Generated interpretations should link back to answers, sessions, goals, or saved research.
- Psychological scores are reflective signals, not diagnoses.
- Brain answers can synthesize into profile fields, but the raw answer history remains the source of truth.
